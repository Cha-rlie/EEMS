# EEMS
## About
Educational Economic Market – Simulated, also known as "EEMS", is a very different educational tool. We made it in response to the notable lack of exciting teaching media when learning essential Grade 7 economics. There was limited student engagement in content, so we sought to create something ‘hands-on’ that would make learning about the Circular Flow of Income Model (a fundamental economics model) a more exciting activity. The tool took the form of a gamified simulation containing a circular flow of income model, with variables controlling the flow of currency between agents in the economy (consumer, producers, government, financial sector, foreign government). It was built with Python programming, economic theory and visual arts skill and it teaches the relationships between the sectors of the economy.
## Features
- Interactive economical simulation
- Graphs that update in real-time
- Animated movement
- Cute robot avatar
